# M0 真机验证清单

> 2026-10-18：设备已连接，静态读数已完成（见 [M0 真机读数](m0-results.md)）。
> 本清单只剩「需要按按键」的项目。

## 0. 型号（已确认）

- [x] 屏幕 2.4 英寸、320×240
- [x] 无 micro:bit 插槽（独立主板）
- [x] 编辑器硬件目标：**F4**

## 1. 烧录链路（已确认）

- [x] USB 识别为 `ELECFREAKS / Arcade`
- [x] 引导区挂载为 `/Volumes/ARCADE-F4`（4.1 MB）
- [x] Bootloader v2.8.1 W，Board-ID `STM32F412-Arcade`
- [ ] 从编辑器成功烧入 `firmware/m0-test.ts`（见下）
- [ ] 记录：点击下载 → 设备重启完成：____ 秒

## 2. 烧测试程序

1. 打开 <https://arcade.makecode.com/>，新建项目。
2. 切到 **JavaScript**，用 [`firmware/m0-test.ts`](../firmware/m0-test.ts) 的内容替换 `main.ts`。
3. 硬件选 **F4**，下载到 `ARCADE-F4` 盘。
4. 屏幕顶部：左边数字 = A 键累计次数，右边数字 = 当前 FPS。

## 3. 按键

- [ ] 十字键：能移动/切换（如果测试程序没有移动，至少确认没有卡死）
- [ ] A：数字 +1，并响一声
- [ ] B：生成 24 个移动方块，再按一次清除
- [ ] Menu：弹出操作说明
- [ ] Reset：复位后程序重新开始
- [ ] 电源键单击开机 / 双击关机

记录任何「按了没反应」或「映射错位」的键：____________
