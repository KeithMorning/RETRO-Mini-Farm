# Mini Farm 游戏设计 v0.2

> 目标：在 RETRO Arcade（320×240、96 MHz、256 KB RAM）上做一款**迷你星露谷**。
> v0.2 根据拍板结果调整：**每季 28 天 × 4 季（一年 112 天）**、**3 个 NPC / 5 心 / 送礼**、**5 个可进入的室内**。

---

## 0. 一句话

**让小镇重新热闹起来：完成三条故事线，并和 Mira、Tom、Lily 都成为 3 心朋友；年底结算「第一年」。没有金钱终点。**

- 春：没有金钱目标，继续经营
- 冬末：3 条故事线完成 + 3 人 3 心 → 年度结局
- 最佳结局：3 人 5 心 + 小恐龙
- 没有硬失败；没达成可以继续玩

## 1. 设计支柱

| 支柱 | 做法 |
|---|---|
| 短会话 | 一天 6–8 分钟；睡觉即存档 |
| 看得懂 | 大字体 HUD：季节/日、时间、金币、体力、种子 |
| 有节奏 | 28 天一个季节，季节换色、换作物、换商店 |
| 有温度 | 3 个村民有家、有作息、会走路、记得礼物 |
| 轻压力 | 无战斗、无死亡；体力用完回家睡觉 |

## 2. 核心循环

```
6:00 起床（玩家家）
  → 农场：浇水 / 收获 / 锄地 / 播种
  → 镇上：买当季种子、出货、和 NPC 聊天/送礼
  → 回家：把作物放进出货箱
  → 上床睡觉
      → 结算：浇过水的作物 +1 阶段；出货箱结算金币
      → 次日 6:00；第 28 天结束进入下一季
```

## 3. 星露谷种菜机制：保留什么

| 机制 | 星露谷 | 我们 |
|---|---|---|
| 时间 | 6:00–2:00 实时 | 6:00–24:00，约 7 分钟一天 |
| 体力 | 270 | 30，每次动作 -1 |
| 浇水 | 水壶容量，水源补 | 15 格，池塘补满 |
| 生长 | 每天检查浇水 | 一样，睡觉时结算 |
| 季节 | 28 天 × 4 | **一样：28 天 × 4，一年 112 天** |
| 作物 | 几十种，品质/肥料 | **16 种**（每季 4 种，冬季 2 种），3 阶段，无品质 |
| 收获 | 手/镰刀，部分再生 | 手收；草莓/玉米/番茄/蓝莓/蔓越莓/葡萄/雪豆可再生 |
| 经济 | 商店买种，出货箱隔夜卖 | 一样，简化价格 |
| 天气 | 晴/雨/雷/雪 | **雨/雪**：雨浇所有作物；雪是冬季视觉 |
| 自动化 | 洒水器/温室/酿造 | 不做 |
| 动物/钓鱼/矿/战斗 | 有 | 不做 |
| 技能/等级 | 有 | 不做；用金币/好感/年度目标代替 |

### 3.1 土壤状态机

```
草地/花丛 --锄头--> 翻土 --种子--> 幼苗(0)
  --水壶--> 已浇水 --睡觉--> 阶段+1，浇水清空
  --成熟--> 收获 -> 翻土（或保留，再生作物）
```

- 已浇水的土颜色更深 + 小水滴。
- 成熟作物有金色闪光。
- 换季时，非当季作物直接消失（提示「季节变了，旧作物枯萎了」），不保留枯萎贴图。

### 3.3 工具与体力

| 动作 | 体力 | 时间 | 说明 |
|---|---:|---:|---|
| 锄地 | -1 | +10 分 | 草地→土 |
| 播种 | -1 | +10 分 | 消耗 1 包当季种子 |
| 浇水 | -1 | +10 分 | 水壶 -1；空了去池塘 |
| 收获 | -1 | +10 分 | 产物进背包/出货箱 |
| 走路 | 0 | 实时 | 不扣 |
| 睡觉 | 回满 | 次日 6:00 | 自动存档 |

- 水壶 15 格；池塘边按 A 补满。
- 体力 0：只能走路，提示回家。
- 24:00 自动睡着；次日体力 70%（温和惩罚）。

### 3.4 出货 / 商店

- 出货箱在家门口；收获物放进去，睡觉结算金币。
- HUD 显示 `BIN 25G`。
- 商店在镇上，9:00–17:00；只卖**当季**种子（4 种，冬季 2 种）。
- 买种：A 买 1 包；B 退出；钱不够提示。

## 4. 时间、季节、一年

### 4.1 时钟

- 6:00 起床，24:00 强制结束。
- 1 游戏分钟 ≈ 0.4 秒 → 一天约 7 分钟。
- 动作额外 +10 分钟（连同体力消耗）。
- 商店 9:00–17:00；NPC 按小时作息。

### 4.2 季节

| 季节 | 天数 | 主色 | 天气 | 商店 |
|---|---:|---|---|---|
| 春 | 28 | 嫩绿/粉花 | 晴/雨 | 春种子 |
| 夏 | 28 | 深绿/亮光 | 晴/雨 | 夏种子 |
| 秋 | 28 | 橙/棕 | 晴/雨 | 秋种子 |
| 冬 | 28 | 白雪/蓝灰 | 雪 | 冬种子 |

- 第 28 天睡觉 → 淡出 → `SUMMER` / `FALL` / `WINTER` / `SPRING` 标题 → 换季。
- 换季时：非当季作物消失；商店换货；地表调色板切换；NPC 对话换季。
- 冬季地表覆雪；树变枯枝（调色板实现）；池塘结冰（视觉）。

### 4.3 目标

- **春季目标**：没有金钱目标；春天只是第一季。
- **年度目标**：第 112 天结束时完成 3 条故事线，且 3 个 NPC 均 ≥ 3 心 → 年度结局。
- **最佳结局**：3 个 NPC 均 5 心，并且解锁小恐龙。
- 未达成：可以继续下一年（内容不锁）。

## 5. 世界与场景

| 场景 | 尺寸 | 相机 | 内容 |
|---|---|---|---|
| 农场 | 40×30 | 跟随 | 玩家家、农田、池塘、出货箱、树 |
| 小镇 | 40×30 | 跟随 | 商店、3 个 NPC 家、广场、路灯 |
| 玩家家 | 20×15 | 固定 | 床、桌子、箱子（后期）、门 |
| 商店 | 20×15 | 固定 | 柜台、货架、店主、门 |
| Mira 家 | 20×15 | 固定 | 床、桌、Mira、门 |
| Tom 家 | 20×15 | 固定 | 床、桌、Tom、门 |
| Lily 家 | 20×15 | 固定 | 床、桌、Lily、门 |

**共 7 个场景 / 5 个室内。**

- 玩家家在农场；商店和 3 个 NPC 家在小镇。
- 室内固定一屏 320×240；室外相机跟随、夹边界。
- 门：淡出 0.2s → 加载 → 淡入；门有目标场景/坐标/朝向。
- 碰撞：树、水、墙、栅栏、家具、柜台不可走。

## 6. 社交

### 6.1 角色

| 角色 | 身份 | 家 | 喜欢 |
|---|---|---|---|
| Mira | 商店店主 | 小镇 Mira 家 | 南瓜 |
| Tom | 邻居老农 | 小镇 Tom 家 | 土豆 |
| Lily | 邻家小孩 | 小镇 Lily 家 | 草莓 berry |

### 6.2 作息（示例）

| 时间 | Mira | Tom | Lily |
|---|---|---|---|
| 6–9 | 家 | 家 | 家 |
| 9–12 | 商店 | 农场/广场 | 广场 |
| 12–14 | 商店 | 家 | 家 |
| 14–17 | 商店 | 广场 | 池塘 |
| 17–20 | 广场 | 广场 | 广场 |
| 20–6 | 家 | 家 | 家 |

- 走路：预设 waypoint，直线移动 + 碰撞；2 帧动画。
- 对话时停下；玩家进室内时，若 NPC 在对应时段在家，就在家。
- 家门外有门牌；晚上门可进（不锁，方便孩子）。

### 6.3 对话 / 好感

- 靠近按 A：名字 + 1–3 行；A 继续，B 关闭。
- 每天第一次对话 +1；送礼 +2，喜欢 +5；每天各一次。
- 0–100 点，20 点 1 心，最多 5 心。
- 对话分 3 档：0–1 心 / 2–3 心 / 4–5 心；每档 2–3 句；随季节换一句。
- 送礼物：手持作物按 A；NPC 有喜欢/普通/不喜欢三种反应。
- 不做恋爱/结婚/节日；3 心触发一段小剧情台词。

## 7. UI

### 7.0 可读性规则（重要）

孩子上三年级，阅读有点困难，所以 UI 文本必须遵守：

- **全部小写**，只有按键标签 `A` / `B` 保留大写（避免和冠词 a 混淆）。
- 字号：HUD / 对话框 / 商店 / 标题统一用 **2× 字体（12×16）**，不再用 6×8 小字。
- 用短词：
  - `carrot` / `potato` / `cabbage` / `berry`
  - `seed` / `bin` / `goal` / `have` / `buy` / `exit`
  - `good morning` / `new season` / `too tired` / `no seeds`
- 不用长句；对话框每页最多 2 行，每行 < 24 个字符。
- 数字和金币用金色；标签用白色 + 黑描边。
- 后续加图标（种子袋、金币、水滴）减少阅读量。

### 7.1 HUD

```
spring 1  06:00          50g
[energy ███████░░]  seed 5   bin 25   96m
```

- 第一行：季节缩写 + 日、时间、金币。
- 第二行：体力、当前种子、出货箱、主频（调试）。
- 字体 6×8；数字金色，文字白色 + 黑描边。

### 7.2 对话框

- 底部 3 行，深色底；左上角名字；A 翻页，B 关闭；逐字显示可选。

### 7.3 商店

- 覆盖面板：当季种子 4 行 + 价格 + 金币；A 买，B 退出。

### 7.4 暂停菜单（M5）

- 目标、好感、季节日历、存档/退出。

## 8. 存档

- 一个槽位，内部 Flash 保留扇区；睡觉/换季自动存。
- 数据 < 512B：
  - 版本、年、季、日、时间、金币、体力、天气
  - 玩家场景/坐标/朝向
  - 农田 24 格：作物 id、阶段、浇水
  - 种子（当季 4 种）、产物、出货箱
  - 3 NPC：好感点、今日对话/送礼、小剧情旗标
  - 目标/结局旗标
- 校验和 + 版本；读失败重开。

## 9. 技术架构

```
src/
  main.c      设备层：LCD/按键/时钟/UF2
  game.c      状态机、主循环、场景切换、日历
  scene.c     7 个场景、碰撞、门、相机
  crops.c     16 种作物、生长、换季
  actor.c     玩家/NPC 移动、动画
  npc.c       作息、对话、好感
  ui.c        HUD、对话框、商店、菜单
  save.c      Flash 存档
  assets.c    瓦片/角色/头像/季节调色板
  font8.c     6×8 字体
```

### 9.1 数据驱动

- `CropDef { id, season, days, seed_cost, sell, regrow, name }`
- `NpcDef { id, home_scene, waypoints, lines[3][3], favorite }`
- `DoorDef { scene, x, y, target_scene, tx, ty, dir }`
- `SceneDef { w, h, tiles, spawn, doors }`

### 9.2 内存

| 项 | 估算 |
|---|---:|
| 帧缓冲 320×240×2 | 153.6 KB |
| 7 个场景地图 | ~3 KB |
| 作物 24 格 ×3 | ~0.1 KB |
| NPC/玩家/实体 | ~1 KB |
| UI/对话/存档 | ~3 KB |
| 代码/栈/堆 | ~25 KB |
| **余量** | **~70 KB** |

Flash：App ~20 KB；16 作物 ×3 阶段（程序化）、4 季调色板、7 场景瓦片、对话/头像 < 150 KB；448 KB 宽裕。

### 9.3 性能

- 96 MHz 已解锁；全屏 blit 仍是主要开销。
- 3 NPC + 24 作物压力很小。
- 掉帧时：局部刷新/HUD 缓存；暂不做双缓冲。
